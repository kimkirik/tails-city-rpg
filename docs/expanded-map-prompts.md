# Expanded map assets

Generated with the built-in image generation tool, one call per region. Assets are stored in this repository; runtime does not depend on external image URLs. Each full-size square has its own artwork. The game supplies inhabitants, shops, enemies, raid entrances and blocked gates separately according to region type. Road center coordinates in `lib/game/regions.ts` align collision with the generated paths.

### Region 6

Saved asset: `public/art/regions/6.png`

Use case: stylized-concept. Asset: square top-down 2D RPG game map Wildflower Outskirts. Beautiful high detail retro pixel art matching a cozy handheld monster-collecting RPG with dogs. Scene: a wildflower meadow outside a town, pink and yellow flowers, low mossy stone walls, winding garden hedges, an old empty ranger lookout, sunlight, no houses or shops. An outdoor combat wilderness. World geometry MUST have a clear straight walkable main path 9% of image width centered exactly x=50%, running from top edge to bottom edge; and a straight horizontal path 8% tall centered y=47.4%, running left edge to right edge. All other decorative areas not walkable. Keep central cross paths empty and unobstructed. No central fountain, no characters, no monsters, no dogs, no text, no icons, no border, no UI, no cave entrances, no shop stalls; these are added by game engine. Fill entire square canvas. Flat overhead camera, crisp richly detailed pixel art. 2048x2048.
